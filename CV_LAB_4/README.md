# CV LAB 4 – Edge Detection

## Aim

To implement and compare different edge detection techniques using OpenCV and NumPy.

## Libraries Used

- OpenCV
- NumPy
- Matplotlib

## Experiment

In this experiment, edge detection is performed on a grayscale image using three different techniques.

### 1. Sobel Edge Detection

Sobel edge detection is applied using horizontal and vertical gradients with a 3 × 3 kernel.

### 2. Prewitt Edge Detection

Prewitt edge detection is implemented using horizontal and vertical Prewitt kernels.

### 3. Canny Edge Detection

Canny edge detection is applied using threshold values 100 and 200.

## Methods Used

- Sobel X and Y gradients
- Prewitt X and Y kernels
- Canny edge detection

## Output

The output compares:

- Original Image
- Sobel Edge Detection
- Prewitt Edge Detection
- Canny Edge Detection

## Result

Sobel, Prewitt and Canny edge detection techniques were successfully implemented and compared on the input image.
